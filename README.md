# Routeliner

Routeliner - модуль QGIS, который ставит на оси дорог, путей, трубопроводов и
линий электропередачи записи таблиц с пикетом вместо координат. Модуль читает пять принятых в СНГ записей пикета и
учитывает ведомость с рублеными пикетами и пикетажными уравнениями.

Каждая запись либо ставится на карту, либо попадает в таблицу ошибок с кодом
причины. По маршруту строится продольный профиль с отметками растров, уклонами
и пикетами по ведомости.

## Инструменты

Инструменты лежат в панели «Инструменты анализа» в группе Routeliner и
повторены в меню «Модули - Routeliner» с теми же номерами.

| Номер | Инструмент | Результат |
|---|---|---|
| 1.01 | Демонстрационный пример | GeoPackage с эталонными ответами и самопроверка модуля |
| 1.02 | Проверка маршрутов | Собранные маршруты, разрывы и развилки |
| 2.01 | Точечные события | Точки по пикету со смещением от оси |
| 2.02 | Участки (линейные события) | Отрезки маршрута между двумя пикетами |
| 3.01 | Динамический слой точечных событий | Слой, который пересчитывается после правок исходных данных |
| 3.02 | Динамический слой участков | То же для участков |
| 4.01 | Пикетная разбивка | Точки целых пикетов с учётом уравнений |
| 4.02 | Привязка точек к маршрутам | Мера, пикет и смещение для каждой точки |
| 5.01 | Таблица профиля | Точки профиля с пикетами и отметками растров |
| 5.02 | Чертёж профиля | Продольный профиль с сеткой и развёрнутым планом для компоновки |

## Установка

Модуль ставится из каталога модулей QGIS или из ZIP-архива через пункт
«Модули - Управление модулями - Установить из ZIP». Требуется QGIS 3.40 или
новее, включая QGIS 4 на Qt6, а внешних зависимостей нет, потому что расчёт
идёт на NumPy из состава QGIS.

Язык интерфейса выбирается по языку QGIS, поэтому при русской локали интерфейс
русский, а при любой другой английский.

## Разработка

Ядро в папке routeliner/core не зависит от QGIS и проверяется тестами.

```
python -m pytest
```

Словарь перевода интерфейса собирается из русских строк кода, и после правки
этих строк его нужно пересобрать.

```
python tools/make_translations.py
```

Правила работы описаны в [AGENTS.md](AGENTS.md), история версий
в [CHANGELOG.md](CHANGELOG.md).
