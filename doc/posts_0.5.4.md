## GitHub, заметки к выпуску 0.5.4

- У модуля появилась своя страница на сайте www.informpp.ru.
- Окно «О модуле» и подвал справки каждого инструмента ведут на неё, а GitHub остаётся ссылкой «Исходный код».
- В каталоге модулей QGIS домашней страницей модуля стала страница на сайте.
- Руководство в PDF пересобрано с новым подвалом.

- The plugin now has its own page on www.informpp.ru.
- The About window and the footer of every tool help link to it, and GitHub stays as the Source code link.
- In the QGIS plugin catalogue the home page of the plugin is now the site page.
- The PDF manual is rebuilt with the new footer.

Страница модуля - https://www.informpp.ru/главная-страница/qgis-routeliner

## ВК, vk.ru/qgismodules

```
Routeliner 0.5.4 - у модуля появилась своя страница на сайте

Routeliner ставит на ось дороги, трубопровода или линии электропередачи записи, у которых вместо координат указан пикет, и учитывает ведомость с пикетажными уравнениями, как принято в СНГ.

```
